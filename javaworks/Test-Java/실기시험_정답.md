## 문제 1. 프로젝트 및 패키지 생성

3. `exam.util` 패키지를 만들고 `DBUtil.java`, `InputUtil.java`를 문제에 제시된 코드 그대로 복사

```java
package exam.util;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class DBUtil {
    private static final String URL =
            "jdbc:mysql://localhost:3306/HR?serverTimezone=Asia/Seoul&characterEncoding=UTF-8";
    private static final String USER = "root";
    private static final String PASSWORD = "1234";

    static {
        try {
            Class.forName("com.mysql.cj.jdbc.Driver");
        } catch (ClassNotFoundException e) {
            throw new RuntimeException(e);
        }
    }

    public static Connection getConnection() throws SQLException {
        return DriverManager.getConnection(URL, USER, PASSWORD);
    }
}
```

```java
package exam.util;

```

## 문제 2. BMI 계산기

```java
package exam;

import exam.util.InputUtil;

public class BmiCalculator {
    public static void main(String[] args) {
        while (true) {
            double heightInput = InputUtil.readDouble("키를 입력하세요 (cm 또는 m): ");
            double heightM = heightInput > 100 ? heightInput / 100 : heightInput;

            double weightKg = InputUtil.readDouble("몸무게(kg)를 입력하세요: ");

            double bmi = weightKg / (heightM * heightM);

            String result;
            if (bmi < 18.5) {
                result = "저체중";
            } else if (bmi < 23) {
                result = "정상";
            } else if (bmi < 25) {
                result = "과체중";
            } else if (bmi < 30) {
                result = "비만";
            } else {
                result = "고도비만";
            }

            System.out.printf("BMI: %.2f%n", bmi);
            System.out.println("판정: " + result);

            String again = InputUtil.readLine("계속 하시겠습니까? (y/n): ");
            if (!again.equalsIgnoreCase("y")) {
                System.out.println("프로그램을 종료합니다.");
                break;
            }
        }
    }
}
```

**채점 기준**
- BMI 계산 (5점): `BMI = 몸무게 / (키(m) × 키(m))` 계산식이 정확하고, 저체중(18.5 미만)/정상(18.5~23 미만)/과체중(23~25 미만)/비만(25~30 미만)/고도비만(30 이상) 5단계를 정확히 판정하여 출력
- 반복 + 종료 (5점): `while(true)` 등으로 반복하며, 계산 후 "계속 하시겠습니까? (y/n)"를 물어 `y`가 아니면 `break`로 정상 종료됨
- 단위 자동 환산 (5점): 입력값이 100을 초과하면 cm으로 간주해 100으로 나눠 m로 환산하고, 100 이하이면 이미 m 단위로 간주해 그대로 사용함

## 문제 3. 학생 클래스와 리스트

```java
package exam;

public class Student {
    private String name;
    private int score;

    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    public String getName() { return name; }
    public int getScore() { return score; }

    @Override
    public String toString() {
        return "이름: " + name + ", 점수: " + score;
    }
}
```

```java
package exam;

import java.util.ArrayList;
import java.util.List;

public class StudentMain {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>();
        students.add(new Student("홍길동", 90));
        students.add(new Student("김철수", 75));
        students.add(new Student("이영희", 60));

        for (Student s : students) {
            System.out.println(s);
        }
    }
}
```

**채점 기준**
- 4점: `Student` 클래스가 다이어그램대로 `name`/`score` 필드, 생성자, `getName()`/`getScore()`를 정확히 갖춤
- 3점: `StudentMain`에서 서로 다른 학생 3명을 생성함
- 3점: `Student.toString()`을 `"이름: 홍길동, 점수: 90"` 형식으로 재정의하여 `List<Student>`의 각 학생 정보를 정상 출력함

## 문제 4. 사원 목록 조회

```java
package exam;

public class Employee {
    private String empId;
    private String empName;
    private Integer salary;

    public Employee(String empId, String empName, Integer salary) {
        this.empId = empId;
        this.empName = empName;
        this.salary = salary;
    }

    public String getEmpId() { return empId; }
    public String getEmpName() { return empName; }
    public Integer getSalary() { return salary; }

    @Override
    public String toString() {
        return "사번: " + empId + ", 이름: " + empName + ", 급여: " + salary;
    }
}
```

```java
package exam;

import exam.util.DBUtil;
import java.sql.Connection;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.util.ArrayList;
import java.util.List;

public class EmployeeDao {
    public List<Employee> findAll() throws SQLException {
        String sql = "SELECT EMP_ID, EMP_NAME, SALARY FROM EMPLOYEE";

        List<Employee> list = new ArrayList<>();

        try (Connection conn = DBUtil.getConnection();
             PreparedStatement pstmt = conn.prepareStatement(sql);
             ResultSet rs = pstmt.executeQuery()) {

            while (rs.next()) {
                list.add(new Employee(
                        rs.getString("EMP_ID"),
                        rs.getString("EMP_NAME"),
                        (Integer) rs.getObject("SALARY")
                ));
            }
        }

        return list;
    }
}
```

```java
List<Employee> employees = new EmployeeDao().findAll();
for (Employee e : employees) {
    System.out.println(e);
}
```

**채점 기준**
- 3점: `Employee` 클래스가 다이어그램대로 필드/생성자/getter/`toString()`을 갖춤 (`"사번: 200, 이름: 선동일, 급여: 8000000"` 형식)
- 4점: `EmployeeDao.findAll()`이 `exam.util.DBUtil`로 연결하여 `PreparedStatement`로 `EMPLOYEE`를 조회하고 `ResultSet`을 `Employee`로 매핑함
- 3점: 결과를 `List<Employee>`에 담아 콘솔에 출력하고, `try-with-resources`로 자원을 해제함

## 문제 5. 람다식으로 급여순 정렬하기

```java
package exam;

import java.util.Comparator;
import java.util.List;

public class EmployeeSorter {
    public void sortBySalaryDesc(List<Employee> empList) {
        empList.sort((a, b) -> b.getSalary() - a.getSalary());

        // 또는 Comparator 정적 메서드 활용
        // empList.sort(Comparator.comparing(Employee::getSalary).reversed());

        for (Employee e : empList) {
            System.out.println(e);
        }
    }
}
```

**채점 기준**
- 2점: `EmployeeSorter.sortBySalaryDesc(List<Employee>)` 시그니처가 다이어그램과 일치함
- 2점: `Comparator` 람다식(또는 메서드 참조)으로 급여 **내림차순** 정렬 결과가 정확함
- 1점: 정렬된 리스트를 순회하며 출력함
